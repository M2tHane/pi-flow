# 数据库规则

1. 迁移只增不改：已合入的迁移文件不得修改或删除。
2. 迁移文件名使用时间戳：YYYYMMDDHHMMSS_<动作>_<对象>.sql（或框架等价形式）。
3. 每个迁移都提供可执行的回滚（down）；无法回滚的变更须在 handoff 中说明并 flow_block 请用户确认。
4. 表名用复数蛇形（order_items），列名用蛇形，主键统一为 id。
5. 外键列命名为 <被引用表单数>_id，并显式声明外键约束与删除策略。
6. 每个用于查询过滤或连接的列都要有索引；唯一约束用唯一索引表达。
7. 时间列统一 created_at、updated_at，带时区。
8. 大表变更（加非空列、改类型）分多步迁移：加可空列 → 回填 → 加约束。
