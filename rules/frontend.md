# 前端规则

1. 组件分层：pages（路由页面）→ features（业务组件）→ components/base（基础组件）；下层不得 import 上层。
2. 只使用基础组件与设计 tokens；不得写原始颜色、间距、字号值。
3. 请求只经请求层（src/web/api/**），统一处理认证与错误；组件中不得直接调用 fetch。
4. 服务端数据放在请求层缓存中；全局状态只放跨页面的客户端状态。
5. 软依赖阶段对着契约写 mock，mock 放在请求层，切换真实实现不改动组件。
6. 每个请求处理加载中、出错、空数据三种状态；出错时给用户可读的提示。
7. TypeScript 不使用 any；组件 props 有类型定义，接口请求与响应类型来自契约。
8. 可访问性底线：交互元素可键盘操作；图片有 alt；表单控件有关联的 label。
9. 页面按目录自动发现路由，不修改集中路由表。
