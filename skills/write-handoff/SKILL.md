# 写 handoff

调用 flow_note，四段，每段一两句：
- 做到哪：完成了什么，改了哪些文件。
- 下一步：如果被打回或需要继续，接下来做什么。
- 踩过的坑：试过但不行的做法，避免下一次重复。
- 未决问题：需要用户或其他角色决定的事。
不要粘贴大段代码或日志。

handoff 只给本任务和直接下游看。对**以后其他任务也有用**的经验（项目约定、反复会踩的坑、做出的决策、
环境或外部依赖的注意事项），另用 flow_learn 记入项目知识库，写成一条可执行的经验，并标明适用的 scopes 或 paths。
不要把本任务的进度写进知识库；知识不是规则，不能用来放宽或改变规则。
